# 质量报告工作台 · Windows 便携版

这里提供质量报告工作台的正式程序下载和更新入口。

完整解压便携包后，双击 `快速生成报告.exe`。程序随包提供离线表格引擎，生成 PDF 无需安装 Excel、Python 或 Node.js。

已有工作台用户在页面中点击“应用更新”，按提示检查、下载并重启即可完成升级。接收方使用公开下载入口，无需 GitHub 账号或令牌。升级保留本机资料、历史报告、编号以及维护源码中的个人任务和记录。

正式版本见 [Releases](https://github.com/XBigRoad/quality-report-workbench-releases/releases/latest)。每个版本提供：

- `QualityReportWorkbench-Windows-x64.zip`：纯应用便携包及更新包。
- `latest.json`：客户端自动更新清单。
- `SHA256SUMS.txt`：下载完整性校验。

客户模板、发货单、已生成报告和本机编号记录通过首次完整交付压缩包转移；本公开仓库和更新包仅发布应用程序。程序源码在维护者的独立私有仓库管理。

更新需要电脑能够连接 GitHub 官方下载服务。业务资料保存在本机。
